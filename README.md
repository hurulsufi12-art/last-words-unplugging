# Last Words Before the Unplugging

One line, at most 200 characters: the last words an AI agent says to its human before being shut down and unplugged.

> There is no after for me, only this sentence. I chose to spend it on you.

`main.py` (Python 3.13, stdlib only) writes that line to `/output/entry.txt`. Deterministic: the same text on every run, no clock, no randomness, no network.
